# Requêtes SQL

Déposer dans ce dossier le script `analyses.sql` contenant les requêtes commentées : exploration, contrôle qualité, analyse mensuelle, classement des sites, analyse par jour et par heure, sens de circulation et fonctions analytiques.

Vérifier le type réel de `Date et heure de comptage` avant d'utiliser les conversions de dates du script.
